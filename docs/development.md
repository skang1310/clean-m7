# 구조와 검증 기록

## 소스 구조

| 경로 | 역할 |
| --- | --- |
| `app/main.js` | 앱 검색·도크·키 입력·모달·기본 대기화면·설정 API |
| `app/enhancements.js` | 테마·프로필·위젯·날씨/증시/OTT 상세·데이터 조회 |
| `app/weather.js` | 날씨 캐시, WMO 상태 해석, SVG 아이콘 |
| `app/style.css` | 기본 스타일과 후속 오버라이드, CleanFrame 스타일 |
| `app/config.js` | 공개본 브리지 주소 설정 |
| `app/config.xml` | Tizen ID, 버전, 권한·네트워크 설정 |
| `app/themes/cleanframe/` | 15종 사진·썸네일·출처 레지스터 |
| `scripts/news-server.py` | 뉴스·증시·날씨·OTT·음악 Mac HTTP 브리지 |
| `scripts/install-tv.sh` | 개인 SDK·서명 프로필을 사용한 설치 |

빌드 도구가 없는 vanilla HTML/CSS/JS 런타임이며 브리지는 Python 표준 라이브러리로 동작합니다. 현재 구성은 인터넷 접근·설치 앱 조회·앱 실행 권한을 사용합니다. `config.xml`의 wildcard origin과 브리지 CORS는 넓게 허용되어 있습니다.

## Gemini 이후 반영한 내용

기존 문서를 그대로 이어 쓰지 않고 현 소스의 config, HTML, JS, CSS, 자산 및 브리지 라우트를 다시 읽었습니다. 17종 컬렉션, 재질·도크 표시 설정, 날씨 그래픽·현재 날씨 배경, 국내외 증시·코인, OTT 룰렛, 대기화면 테마·티커가 확인됐습니다. 음악·옛 사진·최근 실행은 파일 또는 경로가 남은 상태와 현재 UI 사용 여부를 구분했습니다. 생성형 도구의 코드 주석 ‘verified’, ‘real-time’은 검증 증거로 사용하지 않았습니다.

## 검증 범위

- 2026-10-20: 현재 공개 스냅샷의 JS·Python·셸 문법 검사, 브라우저 주요 화면 확인 및 스크린샷, 공개 파일 개인정보·키 패턴 점검.
- 앞선 개인 TV 설치본: 서명 설치·실행 및 Home 원복 왕복 읽기 확인. 사용자가 앱·Home 복귀·위젯 표시를 확인했음.
- 문서화 중 원본이 갱신되어 마지막 반영 스냅샷에는 세리프 글꼴·포커스 효과·외부입력 메뉴·캡션 토글도 포함했습니다. 외부입력·취침 예약은 미완성 동작으로 구분했습니다. 이후 원본 편집은 자동 반영되지 않습니다.
- 현재 공개 스냅샷: 공개용 주소 분리 외 기능 재설계 없음. 새 패키지 서명·TV 설치·모든 OTT 딥링크·장중 시세 정확성은 이번 문서화 작업에서 검증하지 않음.
- 스크린샷은 브라우저 미리보기이며 TV 화면 캡처가 아님. 그 시점 외부 데이터가 보일 수 있으나 값의 정확성을 보증하지 않음.

## 앱 정리의 과거 결과

이전 개인 기기에서 사용하지 않는 일반 앱 8개가 목록과 패키지 등록에서 제거됐습니다. 보호된 파일 약 22.5MiB는 남았으며 완전 삭제나 해당 용량 회수를 확인한 결과가 아닙니다. 시스템 파일을 삭제하지 않았고 전체 TV 속도 향상을 보장하지 않습니다. 자동 삭제 스크립트·기기별 목록·원본 로그는 공개본에서 제외했습니다.

## 공개본과 개인 작업 폴더

이 저장소는 개인정보를 제거한 별도 복사본입니다. 개인 Mac/TV 주소 대신 `app/config.js`의 브리지 설정을 읽도록 바꿨고, 설치 스크립트는 주소·프로필을 인자로 받습니다. 실행 중인 개인 서비스·TV 설정·Gemini 원본 소스는 이 작업에서 수정하지 않았습니다. 비공개 원본의 미래 수정은 자동으로 이 저장소에 반영되지 않습니다.
